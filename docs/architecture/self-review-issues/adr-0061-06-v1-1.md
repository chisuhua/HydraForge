## ADR 概述

ADR-0061-06 v1.1 amendment 修正 v1 标题"升级 ParsedGraph"为"**独立序列化视图**",Oracle 评审 (session `ses_fcba5e477ffeG9wEBHVhU64J0o`) 识别为 G14 缺口——按 v1 实施会把**训练数据格式**耦合进**运行时图结构**,经典耦合风险。本 amendment 通过引入 `TrajectoryIR` 独立类 + `from_parsed_graph()` 单向 Converter,确保训练数据格式与运行时图结构解耦。
