## ADR 概述

ADR-0080 v1.2 amendment **解耦 D10 Capture (EventLog 数据落盘) 与 Scrub Hook (PII 脱敏)**,Oracle 评审 (session `ses_fcba5e477ffeG9wEBHVhU64J0o`) 识别为 G12 缺口——已 Approved 的 D10 蒸馏数据契约被 Proposed 链锁住 (ADR-0081 → ADR-0082),自进化方向**数据面第一步**永远无法启动。本 amendment 引入 `CaptureMode` 枚举 (Off / Online / Training),允许 Training 模式跳过 scrub 强制 (fail-open + 三重保护),从而在不等 ADR-0081/0082 ship 的前提下启动蒸馏数据采集。
