## ADR 概述

ADR-0061-13 定义 **蒸馏输出格式 (DistillationRecord / IDistillationWriter)**,Oracle 评审 (session `ses_fcba5e477ffeG9wEBHVhU64J0o`) 识别为 G15 缺口——ADR-0061 家族 12 子项中**没有一项覆盖"蒸馏输出层"**,即如何把教师 Agent 的能力**编码**为学生模型的训练数据。本 ADR 是"行为克隆器"契约,GEPA/AFlow/BehaviorCloning 三者都需要它作为输入格式,是蒸馏最小闭环 7 环中的最后一环。
