### 为什么不能简单迁移到 EventBuilder

EventBuilder 当前 API 强制 `payload_.ok = true` (构造通过 `ToolResult::success({}, {})`):

```cpp
// event_builder.h 实际构造:
BusEvent build() const {
  return BusEvent{
    topic_,
    ToolResult::success(payload_.args, payload_.meta),  // ok=true 强制
    std::chrono::steady_clock::now()
  };
}
```

强行迁移 Operation-Result 事件会导致:
- `test_engine_bus_integration` 等依赖 `e.payload.ok == false` 判定业务成败的测试全部失败 (已实测)
- `latency_ms` / `trace_id` / `error_code` 等 subscriber 依赖的可选字段全部丢失
- `tool.audit.denied` 的 PermissionDenied ErrorCode 语义被吞

### 解决路径

`promote-event-builder-full-toolresult-support` follow-up change (估时 0.5-1 天):

1. EventBuilder API 扩展:
   ```cpp
   EventBuilder& ok(bool v);
   EventBuilder& latency_ms(int64_t ms);
   EventBuilder& trace_id(const std::string& tid);
   EventBuilder& error_code(ErrorCode c);
   ```
2. `build()` 改为:
   ```cpp
   BusEvent build() const {
     ToolResult tr = payload_.ok.has_value() && !*payload_.ok
       ? ToolResult::error(payload_.error_code.value_or(ErrorCode::Unknown), "", payload_.meta)
       : ToolResult::success(payload_.args, payload_.meta);
     if (payload_.latency_ms) tr.latency_ms = *payload_.latency_ms;
     if (payload_.trace_id) tr.trace_id = *payload_.trace_id;
     return BusEvent{topic_, tr, std::chrono::steady_clock::now()};
   }
   ```
3. 迁移 8 处 raw BusEvent → EventBuilder
4. §5.11 grep 真正返回 0 行
