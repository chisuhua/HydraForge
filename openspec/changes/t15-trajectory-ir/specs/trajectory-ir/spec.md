# trajectory-ir Specification

## ADDED Requirements

### Requirement: TrajectoryIR 是 ParsedGraph 的独立序列化视图（无继承）

The TrajectoryIR class MUST be a standalone class in `agenticdsl::ir` namespace, with NO inheritance or coupling relationship to `ParsedGraph`. Communication between ParsedGraph and TrajectoryIR MUST only happen through a one-way `from_parsed_graph()` Converter.

#### Scenario: 命名空间与类独立性

- **WHEN** 静态检查 `grep "namespace agenticdsl::ir" include/agenticdsl/ir/trajectory_ir.h`
- **THEN** TrajectoryIR 必须在 `agenticdsl::ir` 命名空间内
- **AND** ParsedGraph 不应被 #included 于此头文件（除 Converter 函数声明所需最小引用）

#### Scenario: ParsedGraph 修改不影响 TrajectoryIR

- **WHEN** 运行 `test_trajectory_ir::converter_unidirectional_invariant`
- **THEN** 修改 ParsedGraph 后，之前生成的 TrajectoryIR::ParsedIR 快照保持不变（值类型 + 浅拷贝）

### Requirement: 三级 IR 结构 (RawIR / ParsedIR / CanonicalIR)

The TrajectoryIR MUST define three IR levels as nested structs:
- `RawIR`: text-near DSL representation
- `ParsedIR`: structured JSON with NodeRecord/EdgeRecord/StepRecord
- `CanonicalIR`: pass pipeline output for backends

#### Scenario: 三级 IR 完整定义

- **WHEN** 运行 `test_trajectory_ir::three_level_ir_complete`
- **THEN** TrajectoryIR 必须包含 RawIR / ParsedIR / CanonicalIR 三个 struct 定义
- **AND** ParsedIR 必须包含 `std::vector<NodeRecord>` / `std::vector<EdgeRecord>` / `std::vector<StepRecord>`

### Requirement: 单向 Converter from_parsed_graph

The `TrajectoryIR::from_parsed_graph(const ParsedGraph& pg)` MUST be a static one-way Converter that produces a `ParsedIR` snapshot. Modifications to ParsedGraph MUST NOT affect already-generated ParsedIR.

#### Scenario: Converter 单向性

- **WHEN** 运行 `test_trajectory_ir::converter_from_parsed_graph_basic`
- **THEN** 输入 ParsedGraph（含 N nodes + M edges），输出 ParsedIR（含 N NodeRecord + M EdgeRecord）
- **AND** EdgeRecord.weight = 1.0（V1 简化）

#### Scenario: V1 Steps 占位

- **WHEN** 运行 `test_trajectory_ir::converter_steps_placeholder_v1`
- **THEN** ParsedIR.steps 可为空数组或占位（V2 集成 ADR-0061-13 DistillationRecord.reward）

### Requirement: V1 Backends (to_sft_data + to_otel_spans)

The TrajectoryIR MUST provide V1 backends `to_sft_data(const CanonicalIR&)` and `to_otel_spans(const CanonicalIR&)` returning `nlohmann::json`. V2 backends (`to_rl_data`, `to_eval_data`) MUST NOT be implemented in V1.

#### Scenario: to_sft_data 序列化

- **WHEN** 运行 `test_trajectory_ir::to_sft_data_basic`
- **THEN** 输出 JSON 必须包含 nodes / edges / steps / sft_metadata 字段

#### Scenario: to_otel_spans 序列化

- **WHEN** 运行 `test_trajectory_ir::to_otel_spans_basic`
- **THEN** 输出 JSON 必须符合 OTLP format（含 trace_id / span_id / parent_span_id / timestamps）

#### Scenario: V2 backends 不可用

- **WHEN** 静态检查 `grep "to_rl_data\|to_eval_data" include/agenticdsl/ir/trajectory_ir.h`
- **THEN** 不应出现 to_rl_data 或 to_eval_data 实现（V2 延后）

### Requirement: V1 Pass 占位 (ConstantFoldingPass)

The TrajectoryIR MUST provide a V1 `ConstantFoldingPass` that is a pass-through placeholder (input equals output). V2 pass pipeline (DeadCodeElim, LoopUnroll) MUST NOT be implemented in V1.

#### Scenario: ConstantFoldingPass 占位

- **WHEN** 运行 `test_trajectory_ir::constant_folding_pass_passthrough`
- **THEN** Pass 输入 CanonicalIR，输出 CanonicalIR 等价（字段值完全相同）

### Requirement: SkillCompiler 占位符升级

The `CompiledSkill::trajectory_ir_hash` field MUST be generated by `TrajectoryIR::hash(const CanonicalIR&)` instead of the placeholder `TrajectoryPlaceholder::hash()` (introduced in commit `21dd622`).

#### Scenario: 真实 TrajectoryIR hash 集成

- **WHEN** 运行 `test_skill_compiler::compiled_skill_trajectory_ir_hash`
- **THEN** `CompiledSkill.trajectory_ir_hash` 必须由 `TrajectoryIR::hash(canonical_ir)` 生成（非占位符硬编码）

#### Scenario: TrajectoryPlaceholder 已删除

- **WHEN** 静态检查 `grep "TrajectoryPlaceholder" include/agenticdsl/types/compiled_skill.h`
- **THEN** 不应再出现 TrajectoryPlaceholder struct（V1 占位已升级）

### Requirement: ParsedGraph 零修改

The V1 implementation MUST NOT modify `src/core/parsed_graph.h` or any existing L0 runtime headers. ParsedGraph MUST remain unchanged as the V1 coupling boundary.

#### Scenario: ParsedGraph 未变更

- **WHEN** `git diff HEAD~1 -- src/core/parsed_graph.h`
- **THEN** 不应有 V1 implementation 相关 diff（ParsedGraph 必须 0 改动）

### Requirement: 独立命名空间与既有契约零耦合

The V1 implementation MUST NOT modify IEvaluator / MutationGovernor / BehaviorRegression / SkillCompiler public APIs. Only SkillCompiler's `TrajectoryPlaceholder::hash()` placeholder may be replaced (per Requirement §6).

#### Scenario: 既有契约 API 不变

- **WHEN** `git diff HEAD~1 -- include/agenticdsl/contract/ievaluator.h include/agenticdsl/contract/imutation_governance.h include/agenticdsl/testing/behavioral_regression.h`
- **THEN** 不应有 API diff（仅有内部实现可调整）

### Requirement: ctest 全量零回归

The `ctest --output-on-failure` MUST report ALL tests PASS with zero regressions relative to the V1 baseline at commit `21dd622` (SkillCompiler ship). Test count MUST grow by exactly 1 (test_trajectory_ir target) or more if SkillCompiler integration tests added new cases.

#### Scenario: ctest 全量 PASS

- **WHEN** 运行 `ctest --output-on-failure`
- **THEN** 所有测试 PASS, 0 failures
- **AND** 测试计数 ≥ 188 (SkillCompiler ship baseline + 1)

#### Scenario: test_trajectory_ir 专项

- **WHEN** 运行 `ctest --output-on-failure -R test_trajectory_ir`
- **THEN** ≥ 8 cases PASS, ≥ 16 assertions

### Requirement: adr_lint + docs_drift_audit 全通过

The `python3 tools/adr_lint.py` MUST exit 0, and `python3 tools/docs_drift_audit.py` MUST NOT introduce new CRITICAL drift.

#### Scenario: adr_lint 全过

- **WHEN** 运行 `python3 tools/adr_lint.py`
- **THEN** 退出码 0, 无 ADR lint 错误

#### Scenario: docs_drift_audit 零新增

- **WHEN** 运行 `python3 tools/docs_drift_audit.py`
- **THEN** TrajectoryIR 相关 drift 为 0 项新增
